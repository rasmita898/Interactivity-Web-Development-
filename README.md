# 📚 Study Hub

A responsive and interactive **Study Hub** website built using **HTML, CSS, and JavaScript**. This project demonstrates fundamental front-end web development concepts including responsive web design, DOM manipulation, form validation, API integration, and user interaction.

## 🚀 Features

- 🏠 Responsive landing page
- 🎨 Clean and modern user interface
- 📱 Mobile-friendly design using CSS Media Queries
- 🌈 Dynamic background color changer
- 🌐 Fetches data from a public REST API
- 📝 Student Registration Form
- ✅ Client-side form validation
- ⚡ Interactive JavaScript functionality
## 🛠️ Tech Stack
| Technology | Purpose |
| HTML5 | Structure of the website |
| CSS3 | Styling and responsive design |
| JavaScript (ES6) | Dynamic functionality |
| Fetch API | Retrieve data from an external API |

## ✨ Functionalities
### 🏠 Home Page
- Welcome section
- About Study Hub
- Responsive layout
### 🌈 Background Color Changer
Users can change the page background color with a single click.
### 🌐 API Integration
Uses the **Fetch API** to retrieve and display data from:
https://jsonplaceholder.typicode.com/posts/1
### 📝 Student Registration Form
The form validates:
- Name
- Email
- Password
If any field is empty, an error message is displayed.
Otherwise, a success message is shown.
## ⚙️ Installation
Clone the repository:
bash
git clone https://github.com/rasmita898/study-hub.git
Navigate into the project folder:
bash
cd study-hub
Open **task8.html** in your browser.
No additional installation or dependencies are required.
